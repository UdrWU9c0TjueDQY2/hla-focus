HOW THE COMPARISON STAYS HONEST

Same rule. Same grid size. New positions.

Five trials each

Both attempts contain five 36-item grids. The target is always one filled circle among outlined circles.

Misses stay visible

Selecting an outlined circle adds one miss and keeps the same trial on screen. The board never subtracts misses.

No population claim

The result compares only your A and B totals from this browser session. There is no norm, percentile, age estimate or diagnosis.

For a fairer self-comparison

  • Use the same device and input method for both attempts.
  • Finish both attempts in one sitting if that is comfortable.
  • Do not read a single result as proof that your everyday focus changed.
