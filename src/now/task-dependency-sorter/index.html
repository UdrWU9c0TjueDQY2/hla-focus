Give each action its prerequisites

Use A, B, C or D separated by commas. Leave prerequisites blank when an action can start now. A blank task is ignored unless another task needs it.

A valid plan can be saved as a text file on your device. It includes your action names and prerequisites, so choose a private place to keep it. Editing any field clears the previous result and download. Nothing is sent or transferred into Now.

Why are both actions waiting?

Watch a 15-second example from the browser sorter. The two actions and the sorter’s results are reformatted for the clip.

Read the transcript

A is “Write the reply” and must follow B. B is “Read the request” and must follow A. The sorter reports a circular dependency. Reading can happen before a reply exists, so clear B’s prerequisite and sort again. B can start now. One valid order is B, read the request, then A, write the reply.

MAKE THE RESULT USEFUL

A dependency is a real prerequisite, not a preference.

“Review the figures” needs the file first. “Choose a title” might not. Avoid linking tasks just because you usually do them in that order.

If the result finds a loop, two or more tasks are waiting on each other. Change the work: write a rough draft before asking for final feedback, for example. Removing a prerequisite in the tool does not remove the real-world constraint.

The output is one valid order, not a priority ranking or schedule. When several tasks are ready, choose the one you can take a small concrete step on.
