How to compare two short texts
Put the version you trust in Reference and the edited version in Revised. Select Show differences. Red marks identify characters removed from the reference; teal marks identify additions in the revision. The text remains selectable.
Why an insertion does not shift every later letter
This checker aligns matching characters in order, using a longest common subsequence. Adding one word can therefore highlight that word without treating the rest of the sentence as changed. Repeated characters may have more than one equally short alignment; this tool chooses one consistently.
Try the example
The sample changes room 214 to 274, removes the hyphen in check-in and adds a second space before 10:30. This is a literal comparison, not a spelling or grammar checker. It cannot decide which version is correct.
What counts as a character?
The limit counts Unicode code points. Some emoji and accented letters contain more than one. Visually similar characters can still differ. Empty text is allowed on one side, but two empty fields produce a prompt instead of a result. Editing either field clears the previous comparison.
Privacy and scope
The comparison runs locally on this page and is not submitted by the tool. Use it for short practice text or non-sensitive drafts. It does not measure attention, diagnose a condition or predict everyday performance.
