USE IT IN REAL LIFE

Make the next rule smaller than the problem.

  1. Record times, not judgments. Write down when you check. Do not log message content, contacts or anything private. This page needs only times.
  2. Look for context. A cluster may be a work task, a conversation or aimless reopening. The chart cannot distinguish them. You can.
  3. Protect one app in one situation. If the cluster is unwanted, start with one distracting app and keep essentials available. Write down the task you will return to.
  4. Check another day. A single log is a snapshot. It is not a diagnosis or proof that your habits have changed.
How the busiest window is chosen

The tool checks 60-minute windows beginning at each logged time. For times after 23:00, it uses 23:00–24:00 so the window stays inside your day. The start is included; the end is excluded. When several candidate windows tie, the earliest appears first. You can choose any tied window for your planning note. Some windows may overlap, so their counts cannot be added together. The hourly chart uses fixed clock hours, so its largest row can differ from the busiest rolling window.

Example: checks at 20:50 and 21:20 fit in the same observed-start window, but appear in different hourly rows. A check exactly at 21:50 is outside a window starting at 20:50. Counts do not imply minutes used or minutes saved.
